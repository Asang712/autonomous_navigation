# Nav2实战阶段2文档解读（Ubuntu24.04 + ROS2 Jazzy适配）
> 原文基于Ubuntu22.04 + ROS2 Humble，**你的环境全部`humble`替换为`jazzy`**。
阶段2核心：跑通**SLAM建图→保存地图→定位模式加载地图→Nav2自主导航完整闭环**。这是整个课程的基准参照链路，**千万不能跳过**。后续写Python、调恢复行为、状态机全部在此基础上叠加。

## 🎯本阶段要完成三件事
1. 使用`slam_toolbox`在线异步建图，键盘遥控机器人走遍房间，形成闭环，保存地图文件`~/nav2_hello_map.yaml`
2. slam_toolbox切换**定位模式**，启动Nav2导航系统
3. RViz点击`2D Nav Goal`目标点，机器人自动规划全局路径、局部避障、自主到达目标位置

>阶段1只是把工具打开看一看；**阶段2才是机器人第一次真正自主运动，不再靠键盘遥控**。

## 🔍前置环境自检（必须全部通过再动手）
>下面命令全部适配Ubuntu24.04 Jazzy

1. 检查ROS2版本
```bash
source /opt/ros/jazzy/setup.bash
ros2 --version
```
输出版本为`jazzy`，如果command not found，把source写入`~/.bashrc`永久生效
```bash
echo 'source /opt/ros/jazzy/setup.bash' >> ~/.bashrc
source ~/.bashrc
```

2. 确认工作空间（后面写Python代码都放这里）
```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
colcon build --symlink-install
echo 'source ~/ros2_ws/install/setup.bash' >> ~/.bashrc
source ~/.bashrc
```
> `--symlink-install`符号链接安装，修改Python脚本不用重复colcon build。

3. 校验软件包是否安装成功
```bash
ros2 pkg list | grep nav2
ros2 pkg list | grep slam_toolbox
```
必须能看到nav2_amcl、nav2_planner、slam_toolbox等包。

4. Python依赖
```bash
pip3 install transforms3d
```

## 🚀分步实操（Ubuntu24.04 Jazzy可复制命令）
>每一个launch**新开一个独立终端**，每个新终端都记得先`source /opt/ros/jazzy/setup.bash`

### 步骤1：启动Gazebo仿真环境
终端1：
```bash
source /opt/ros/jazzy/setup.bash
ros2 launch turtlebot3_gazebo turtlebot3_house.launch.py
```
>保持Gazebo一直运行，不要关闭。

### 步骤2：启动slam_toolbox【在线异步建图模式 online_async】
终端2：
```bash
source /opt/ros/jazzy/setup.bash
ros2 launch slam_toolbox online_async_launch.py \
params_file:=/opt/ros/jazzy/share/slam_toolbox/config/mapper_params_online_async.yaml \
use_sim_time:=True
```
>关键点：
1. `online_async`多线程异步建图，仿真/真机推荐；不要用`online_sync`单线程
2. `use_sim_time:=True` **仿真环境必须打开，使用Gazebo仿真时间**

### 步骤3：键盘遥控机器人，走完整个房间，完成闭环
终端3（键盘控制）
```bash
source /opt/ros/jazzy/setup.bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```
操作：保持该终端选中，方向键控制机器人，把整个屋子全部探索一遍，**最后尽量回到起点附近，完成地图闭环**。
>打开rviz2，添加话题`/map`，可以实时看到地图一点点构建出来。

### 步骤4：保存地图
终端4
```bash
source /opt/ros/jazzy/setup.bash
ros2 run nav2_map_server map_saver_cli -f ~/nav2_hello_map
```
执行完成，家目录生成两个文件：
- `nav2_hello_map.yaml` 地图配置文件（导航加载用）
- `nav2_hello_map.pgm` 灰度图片地图

>⚠️ 保存地图完成，回到【终端2】按`Ctrl+C`关闭**建图模式的slam_toolbox**！建图和定位模式不能同时跑。

### 步骤5：slam_toolbox切换【定位模式 localization】
>use_sim_time改为`False`；加上`localization:=True`，读取已经保存好的地图，只做定位，不再新增建图
终端2（重启slam_toolbox）
```bash
source /opt/ros/jazzy/setup.bash
ros2 launch slam_toolbox online_async_launch.py \
params_file:=/opt/ros/jazzy/share/slam_toolbox/config/mapper_params_online_async.yaml \
localization:=True \
use_sim_time:=False
```

### 步骤6：启动Nav2导航栈
终端5
```bash
source /opt/ros/jazzy/setup.bash
ros2 launch turtlebot3_navigation2 navigation2.launch.py \
use_sim_time:=False \
map:=$HOME/nav2_hello_map.yaml
```

### 步骤7 RViz操作，实现自主导航
1. RViz中`Fixed Frame`修改为`map`坐标系
2. Add添加显示：`/map`地图、代价地图`/global_costmap/costmap`、`/local_costmap/costmap`、规划路径`/plan`
3. 点击工具栏 **`2D Pose Estimate`**：在地图上点击+拖拽箭头，告诉AMCL机器人当前大概位置（必须和Gazebo真实位置接近）
4. 观察粒子云，粒子聚拢在机器人周围 = **AMCL定位收敛成功**
5. 点击工具栏 **`2D Nav Goal`**，在地图点选目标位置，设置朝向。
✅预期效果：Nav2生成全局路径，机器人运动，避开障碍物，自主到达目标。

## ⚠️高频坑：AMCL不收敛、粒子云四散
现象：设置2D Pose Estimate之后，粒子到处散开，机器人不动。
常见原因：
1. 没有把slam_toolbox切换到`localization:=True`定位模式，还停留在建图模式
2. `use_sim_time`参数混淆：建图开True；定位+Nav2开False
3. 初始位姿给的和真实机器人位置差距太大
>排查：确认slam_toolbox启动参数带`localization:=True`
