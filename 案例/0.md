## 逐条10项自检讲解（附带Ubuntu24.04适配）
### 1. ROS2环境能正常启动
文档命令(humble)
```bash
source /opt/ros/humble/setup.bash
ros2 --version
```
✅ **Ubuntu24.04你要执行：**
```bash
source /opt/ros/jazzy/setup.bash
ros2 --version
```
预期输出：显示`jazzy`版本。
- `command not found`：说明你没有安装ROS2 Jazzy，需要安装Jazzy，**不要强行装humble到24.04，会大量依赖冲突**。

### 2. 创建编译工作空间
文档命令
```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
colcon build
```
这条命令系统无关，Ubuntu24.04直接运行。
报错大概率缺colcon工具：
```bash
sudo apt install python3-colcon-common-extensions
```
> 成功：终端无红色报错，生成build install log文件夹。

### 3. 运行turtlesim海龟仿真节点
文档humble：
```bash
source /opt/ros/humble/setup.bash
ros2 run turtlesim turtlesim_node
```
✅24.04：
```bash
source /opt/ros/jazzy/setup.bash
ros2 run turtlesim turtlesim_node
```
预期：弹出海龟小窗口。

**新开另外一个终端（新终端必须重新source！）**
```bash
source /opt/ros/jazzy/setup.bash
ros2 node list
```
输出里面看到`/turtlesim`。
> 知识点：ROS2节点是独立进程，不同终端运行，依靠话题topic通信。

### 4. 查看话题，阻塞监听话题数据
新开终端
```bash
source /opt/ros/jazzy/setup.bash
ros2 topic list
ros2 topic info /turtle1/cmd_vel
ros2 topic echo /turtle1/cmd_vel
```
- `ros2 topic echo`会阻塞终端，**按Ctrl+C退出**。
> 知识点：topic是持续流式发布数据。

### 5. 键盘控制海龟移动
新终端：
```bash
source /opt/ros/jazzy/setup.bash
ros2 run turtlesim turtle_teleop_keyboard
```
保持这个终端是激活状态，按上下左右方向键，海龟窗口海龟移动。
> 原理：键盘节点发布速度消息到`/turtle1/cmd_vel`话题，海龟节点订阅这个话题执行运动，验证话题通信完整链路。

### 6. Service服务（请求‑应答，一次性调用）
新终端
```bash
source /opt/ros/jazzy/setup.bash
ros2 service list
ros2 service call /clear std_srvs/srv/Empty
```
预期：海龟窗口里海龟绘制的轨迹线条全部清空。
> 知识点：Service是**一次性请求响应**，调用一次执行一次，不像topic源源不断发数据。

### 7. Parameter 参数，节点运行时配置
```bash
source /opt/ros/jazzy/setup.bash
ros2 param list
ros2 param get /turtlesim background_b
ros2 param set /turtlesim background_b 200
```
运行完set命令，海龟窗口背景蓝色加深。
>知识点：Parameter是节点的配置，可以启动前设置，也可以程序运行过程动态修改。

### 8. Launch启动文件
>文档没有给命令，概念理解：
launch文件：**一条命令同时启动多个ROS2节点**，Nav2导航会大量使用launch，不用手动开十几个终端。

### 9. Python编写最小ROS2节点【最重要】
新建文件`hello_ros.py`，代码和文档完全一样，Python代码不区分humble/jazzy。
```python
import rclpy
from rclpy.node import Node

class HelloNode(Node):
    def __init__(self):
        super().__init__('hello_node')
        self.timer = self.create_timer(1.0, self.tick)
        self.count = 0

    def tick(self):
        self.get_logger().info(f'hi {self.count}')
        self.count += 1

def main():
    rclpy.init()
    rclpy.spin(HelloNode())
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```
运行：
```bash
source /opt/ros/jazzy/setup.bash
python3 hello_ros.py
```
预期：每秒打印 `hi 0`、`hi 1`、`hi 2`……，`Ctrl+C`终止。
>这一条是重中之重，Nav2实战大量写Python节点，rclpy基础必须过关。

###10. Action动作概念（理解即可，不用写代码）
>Action：长时间执行任务，**支持过程反馈 + 中途取消**。
对比：
- Topic：持续数据流
- Service：短时间一次性请求，不能取消，无过程反馈
- Action：长时间任务（导航移动机器人就是典型Action！Nav2核心就靠Action）

## ⚠原文档“一键安装依赖包”，Ubuntu24.04不能直接复制！
文档apt全部包名是`ros‑humble‑xxx`，你的24.04要改成`ros‑jazzy‑xxx`
文档原命令（仅humble）：
```bash
sudo apt install ros-humble-navigation2 ros-humble-nav2-bringup ...
```

✅ **Ubuntu24.04 Jazzy正确安装命令：**
```bash
sudo apt update
sudo apt install ros-jazzy-navigation2 ros-jazzy-nav2-bringup \
ros-jazzy-turtlebot3* ros-jazzy-gazebo-* \
ros-jazzy-cartographer ros-jazzy-cartographer-ros \
ros-jazzy-teleop-twist-keyboard \
ros-jazzy-slam-toolbox ros-jazzy-tf-transformations \
ros-jazzy-nav2-map-server

pip3 install transforms3d
```
>transforms3d是python库，版本无关，直接pip安装。

安装完成后，正式课程阶段1只需要运行Gazebo + RViz。
